📈 Real-Time Stock Market Dashboard (Excel + Python + Alpha Vantage API)

A real-time stock market analytics dashboard built using Python, Alpha Vantage API, and Microsoft Excel (Advanced Excel). The dashboard automatically updates stock market data, performs analytical calculations, and provides interactive visualizations for quick market insights.

📌 Project Overview

This project demonstrates an end-to-end data analytics workflow where live stock market data is fetched using the Alpha Vantage API, processed with Python, and analyzed through an interactive Excel dashboard.

Instead of manually entering stock prices, the dashboard refreshes automatically whenever new data is generated by the Python script, making it suitable for real-time market monitoring and portfolio analysis.

🎯 Business Problem

Stock market data changes every minute. Investors and analysts need an easy-to-use dashboard that can:

Monitor multiple stocks simultaneously
Compare stock performance
Identify gainers and losers
Analyze trading volume
Categorize stocks into price and volume bands
Filter data dynamically

This project solves these problems using Excel dashboards powered by live API data.
